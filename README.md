# 每日具身智能简报 · Embodied AI Daily

**追踪具身智能前沿，每日精选产业洞察。**

《每日具身智能简报》是一份面向具身智能（Embodied AI）领域的产业日报。内容覆盖技术前沿、学术研究、产品发布、融资动态、企业信息等多个维度，由产业研究团队从网络公开资料中筛选整理，每日自动更新并发布。

## 🔗 在线访问

> **<https://jackie-c-lee.github.io/embodied-ai-daily-brief/>**

每日自动更新。站点支持历史日期回溯、主题浏览与多关键词搜索，所有资讯均可一键跳转原文。

## 内容栏目

简报按主题分类，覆盖以下方向：

- 前沿技术 · 前沿模型 · 学术前沿 · 开源成果
- 产品发布 · 融资动态 · 产业合作 · 产业服务
- 国内企业 · 海外动态 · 政策发布 · 行业数据
- 具身数据 · 前沿展会

## 站点功能

- **每日精选**：最新资讯置顶展示，头部统计累计资讯、整理天数、今日精选与最新日期
- **历史回溯**：历史简报时间轴与迷你日历，支持浏览任意日期的资讯
- **多维筛选**：按主题分布浏览、主题标签筛选，支持多关键词全文搜索
- **阅读体验**：分页浏览、卡片展开阅读，资讯卡片直达原文或公众号来源

## 更新机制

内容由产业研究团队维护于飞书多维表格，GitHub Actions 每日自动同步并部署至 GitHub Pages，实现"整理即发布"。每日 23:30 另有全量同步兜底，确保内容准时、稳定上线。

## 技术架构

```
飞书多维表格  ──▶  GitHub Actions (Node.js)  ──▶  public/data.json  ──▶  GitHub Pages
```

- **前端**：原生 HTML / CSS / JavaScript 单页应用，无构建步骤，加载即用
- **自动化**：GitHub Actions 定时与触发式同步，密钥经 Actions Secrets 注入，仓库内不保存任何敏感信息
- **托管**：GitHub Pages 静态部署，仓库 `Jackie-C-Lee/embodied-ai-daily-brief`

## 数据说明

- 数据来源：网络公开资料，由产业研究团队筛选整理
- 更新频率：每日
- 机构 Logo 与公众号二维码等图片资源随仓库公开托管，供页面直接引用
